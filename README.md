
# Sistema de Empleados ACME S.A. de C.V.

## Objetivo
Crear una aplicación en Python que permita crear una base de datos y registrar empleados.

## Tecnologías utilizadas
- Python
- SQLite
- GitHub
- Visual Studio Code

## Base de datos
Nombre: EMPLEADOS

## Datos de los empleados
- CURP (llave primaria)
- Nombre
- Apellido
- Calle
- Colonia
- Teléfono

## Funcionalidades
1. Crear la base de datos.
2. Dar de alta a los empleados.
3. Evitar CURP duplicadas.
4. Validar los campos obligatorios.

## Ejecución del programa
Abre la terminal de Visual Studio Code y ejecuta:

    python empleados.py
